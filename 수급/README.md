# 코스피·코스닥 투자자별 수급 분석

개인·외국인·기관의 순매수 흐름을 시계열(일간/주간/월간)로 보고,
그 수급이 주가 등락과 어떻게 연결되는지 확인하는 **로컬 웹앱**입니다.

- **데이터 소스**: 네이버 금융 (로그인·API키 불필요)
- **분석 대상**:
  - **지수**: 코스피/코스닥 — 개인·외국인·기관 (단위: 억원)
  - **개별종목**: 코스피200 종목 — 외국인·기관 (단위: 주). 개인은 네이버 미제공
- **화면**: 대상·주기 토글, 종가 vs 누적 순매수선, 투자자별 순매수 막대,
  수급↔주가 상관표, (종목) 외국인 보유율

---

## 실행 방법

### 방법 1: 더블클릭 (가장 쉬움)
`수급분석_실행.bat` 을 더블클릭하면 브라우저에서 앱이 열립니다.

### 방법 2: 명령어로 실행
```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
→ 브라우저에서 http://localhost:8501 자동 오픈

---

## 사용법

1. 왼쪽 사이드바에서 **분석 대상** 선택
   - **지수**: 시장(코스피/코스닥) 선택
   - **개별종목**: 코스피200 종목 드롭다운에서 선택
2. **주기**(일간/주간/월간)와 **조회 기간(개월)** 조정 (3~24개월)
3. **🔄 데이터 새로고침** 버튼으로 네이버 금융에서 최신 데이터 재수집
   - 평소에는 로컬 캐시(`data/*.csv`)를 사용해 빠르게 표시됩니다.

---

## 화면 구성

| 요소 | 설명 |
|------|------|
| 차트1 | 지수 종가(검정) + 외국인(빨강)·기관(파랑) **누적 순매수선** 겹치기 |
| 차트2 | 투자자별 **순매수 막대** (개인·외국인·기관) |
| 상관표 | 각 투자자 순매수 ↔ 지수 수익률 상관계수 (Pearson / Spearman) |

**상관계수 해석**
- `+1`에 가까울수록 → 그 투자자가 살 때 지수가 오른다 (동행)
- `−1`에 가까울수록 → 살 때 오히려 지수가 내린다 (역행)

## 폴더 구조
```
수급/
├─ app/
│  ├─ data_fetch.py    # 네이버 금융에서 지수·투자자별 순매수 수집 + CSV 캐시
│  ├─ analyze.py       # 일→주→월 집계, 누적 순매수, 상관계수
│  └─ streamlit_app.py # 웹 UI
├─ data/               # 수집 데이터 캐시 (자동 생성)
├─ requirements.txt
├─ 수급분석_실행.bat
└─ README.md
```

## 참고
- 단위: 투자자별 순매수는 **억원**, 지수는 **포인트**
- 집계 규칙: 지수는 기간 마지막 종가(last), 순매수는 기간 합계(sum)
- KRX(pykrx)는 최신 버전부터 로그인 계정을 요구해 사용하지 않았습니다.
  네이버 금융은 계정 없이 접근 가능합니다.
