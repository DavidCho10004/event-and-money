## 1. 요약

친구가 제공한 엑셀 프로토타입("★주식 매수 검토")의 컨셉 — 전 종목 투자자별 수급 매트릭스로 매수 후보를 찾는다 — 를 5일간 웹 시스템으로 재구축하고, 그 기반 위에서 "수급이 주가에 선행한다"는 투자 가설을 10년 데이터로 전면 검증했다.

**결과: 약 80개 검증 조합에서 실전 가능한 매수 신호 0개, 통계적으로 견고한 회피 신호 4개.** 도구의 정체성은 "매수 신호 생성기"가 아니라 "종목 발굴 필터 + 회피 경보기"로 확정됐다. 시스템은 주간 무인 운영 체계로 전환됐고(7/17 첫 무인 실행 성공), 모든 검증 결과는 화면과 가설 대장에 반영됐다.

- **매수 검토 스크리너** (/buy-review): 기간 토글(6개월/3개월/1개월/1주일) × 필터 칩(외인 +3%p/+5%p, PBR, 기관 동반, 개인 순매도, 삼박자, 우선주 제외, 순매수 100억↑) × 정렬 4종(변화폭/금액/강도/가속). 카드에 이중 지표(금액+강도), 시장별 순위 배지(100위 컷), 기간 주가 등락 병기
- **플래그 체계**: ⚠상장주식수 변동(±N% 팩트 표기), ⚠장외 지분변동, ⚠개인 몰림(H3 근거 툴팁), 지속형/스파이크형 태그
- **종목 상세** (/buy-review/{코드}): 주가+외인지분율 겹침 차트, 투자자별 주간 순매수 바차트, 네이버 금융 링크
- **수급 분석** (/supply-demand): 시장 조망 — 투자자별 주간/월간 순매수 추이 + 주간 요약 카드
- **백테스트** (/backtest): 전 검증 결과 성적표 + 강건성 열 + 결론 배너 (자기 한계를 화면에 명시)
- **가설 대장** (docs/hypotheses.md): 전 가설의 사전 예상·결과·기각 근거 기록

## 3. 검증 결과 총괄 (~80개 조합)

### 3-1. 검증 방법론

모든 검증에 동일 규율 적용: **사전 가설·예상 고정 → 튜닝 금지 → 강건성 자동 검증**(기간 분할 2016-20/2021-26, 최고 성과 달 상위 3 제거, 거래비용 반영, 랜덤 벤치마크 대비) → 결과 무조건 수용·기록.

### 3-2. 기각된 가설

| 가설 | 내용 | 기각 근거 |
|---|---|---|
| a/b/c 수급 추종 | 삼박자·강도 상위·교집합 매수 (30조합) | 겉보기 +2~3%p가 상위 3개 달 제거 시 소멸 — "10년 초과수익이 복권 3장" |
| d 매집+주가 미반응 | 매집됐는데 아직 안 오른 종목 | 대조군 d′(이미 오른 쪽)에 전 구간 패배 — 모멘텀 동행이 우세, "미반응 필터"는 역효과 |
| H1 폭락 레짐 | 폭락 다음 달만 진입 | 기간 분할 시 두 시장 정반대, 상위 3 제거 시 음수 |
| H2 지속성 (절대) | 3개월 연속 매집 종목 매수 | 서열은 성립하나 랜덤 미달 |
| F1 저PBR | 밸류 팩터 | 기본 검증 전 조합 생존(+5.9~21.0%p)했으나 **유동성 컷 하나에 붕괴**(코스닥 +21.0→+1.0%p) — 살 수 없는 초소형 부실주 구간의 통계적 신기루 |
| F2 모멘텀 | 6개월 상승 추격 | 전 조합 음수, 코스닥 6개월 -15.2%p — 한국 시장 모멘텀 부재 문헌(Chui-Titman-Wei 계열)과 정합 |
| F3 퀄리티 프록시 | ROE≈PBR/PER 근사 | 전 조합 음수 (진짜 재무 데이터로는 미검증) |
| B 빈도 가설 | 순위 진입 빈도 상위 (친구 제안의 규율 버전) | 표본 9~11회로 부족, 소수 달 의존 극단적 |
| A 일별 추종 | 당일 외인 상위 → 익일 | 종가→종가 +0.30~0.45%(유의)로 **신호는 실재**하나, 시가→종가 -0.27~-0.33%(유의 음수) — 시초가 갭이 신호를 과잉 선취, 실행 수단 없음 |
| E2 사건 월 외인 픽 | 사건 국면 외인 매집 상위 | 대체로 무의미 (기존 결과와 정합) |

### 3-3. 살아남은 발견 (회피 신호 4 + 서열 지식 2)

**회피 신호 — 통계적으로 견고, 실전 적용 가능:**

1. **개인 몰림 회피 (H3)**: 개인 순매수 강도 상위 종목은 코스피 1~3개월 유의한 저성과 (t=-2.4~-3.7, 20셀 중 18개 음수). 전체 검증에서 유일하게 t>2를 넘긴 평상시 신호
2. **사건 국면 개인 몰림 — 최강 발견 (E1)**: 사건 월(36건)에 개인이 몰린 코스닥 종목은 6개월 후 랜덤 대비 **-9.7%p (t=-3.16)**, 상위 3 사건 제거 시 **-13.4%p로 오히려 강화** — 소수 사건 의존이 아닌 광범위 분산. 위기 국면의 개인 매수(물타기·낙폭과대 베팅)는 평상시보다 4배 나쁘다
3. **코스닥 모멘텀 추격 금지 (F2)**: 오른 종목 추격이 6개월 랜덤 대비 -15%p
4. **시초가 갭 추격 금지 (A)**: 외인 순매수 상위 공개 후 다음날 시가 매수는 일평균 -0.3% 유의 손실 — 갭을 물어주는 쪽이 된다

**서열 지식 — 절대 우위는 없으나 방향 일관:**

- 강도(주식수 대비 %) > 금액: 규모 다른 종목 간 매집 비교의 올바른 자 (친구 프로토타입의 물량기준 직관 타당)
- 지속형(3개월 연속) > 스파이크형(단월 급증): 전 검증에서 서열 일관

**사건 수급의 구조적 관찰 (콘텐츠 가치):**

- 위기마다 "외인·기관 매도 / 개인 매수" 구조 반복: 코로나(외인 -12.6조/개인 +11.2조) → 7/13 폭락(-3.9조/+4.6조)
- 예외 존재: 러-우 전쟁(외인 순매수), IPO 국면(역전) — 사건 유형별 수급 반응 분류 가능

## 4. 핵심 교훈

1. **공개 정보에는 우위가 없다**: 장 마감 후 전면 공개되는 수급 정보는 다음 거래 기회(시초가)에 이미 과잉 반영된다. A 검증의 분해(종가→종가 유의 양수 vs 시가→종가 유의 음수)가 이를 직접 증명
   - **메커니즘 — 외국인은 단일 주체가 아니다**: "외국인 순매수"는 패시브(지수 복제 — 종목 판단이 없음), 액티브(국가·섹터·매크로 배분이 우선), 차익거래(현·선물 베이시스 — 방향성 정보 없음)의 합계다. 합산 숫자에 종목 단위 정보가 옅을 수밖에 없고, 정보가 실제로 담긴 액티브 부분조차 공개 정보 기반이라 가격에 즉시 반영된다. "외국인을 따라 사면 된다"는 직관이 80개 검증에서 전부 무너진 구조적 이유
2. **강건성 검증이 착시를 걸러낸다**: 기간 분할·상위 3 제거·유동성 컷·비용 반영 없이는 "+21%p" 같은 신기루를 믿게 된다. 이번 탐색에서 겉보기 좋은 결과의 전부가 이 관문에서 무너졌다
3. **회피가 수익이다**: 발견된 4개 신호는 전부 "하지 마라"다. 개인투자자 손실의 주요 경로(몰림 매수·추격 매수·갭 추격)를 자기 데이터의 t-통계로 확인한 것 — 잃지 않는 형태의 수익
4. **검증 규율**: 사전 예상 기록, 조합 수 통제, 대조군 설계(d′, E2), 사건별 낱장 확인이 데이터 마이닝과 검증을 가르는 선
