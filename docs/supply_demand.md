# 코스피/코스닥 투자자별 수급 분석

개인·외국인·기관의 **순매수(수급)**를 일·주·월 시계열로 보고, 그 흐름이 지수 등락과
어떻게 연결되는지 확인하기 위한 파이프라인입니다.

## 목적 (한 문장)
> "누가(개인/외국인/기관) 얼마를 순매수/순매도했는지 시계열로 보여주고,
> 그 수급이 코스피·코스닥 지수 등락과 어떻게 연결되는지 데이터로 확인한다."

## 로직 (설계 합의안)

| 단계 | 내용 |
|------|------|
| ① 수집 | pykrx(KRX)에서 지수 종가 + 투자자별 **순매수 거래대금(원)** 일별 수집 |
| ② 집계 | 일 → 주(금요일 종료) → 월(월말). 종가=마지막값, 순매수=**합계** |
| ③ 연결 A | **누적 순매수선**을 지수에 겹쳐, 수급-주가 동행 여부를 눈으로 확인 |
| ③ 연결 B | **기간 순매수 vs 같은 기간 지수 수익률**의 Pearson/Spearman 상관 |
| ④ 시각화 | 상단=지수+누적순매수선 / 하단=투자자별 순매수 막대 (증권사 HTS 스타일) |

- **수급 지표**: 순매수 거래대금(원) 기준. 순매수 = 매수 − 매도. 양수=매집, 음수=차익실현.
- **색상**: 외국인=빨강, 기관=파랑, 개인=회색 (한국 관행).
- **단위**: 차트/집계 CSV는 가독성을 위해 **억원**으로 환산.

## 실행 방법 (규훈님 로컬 Windows)

```bash
# 0) 최초 1회 패키지 설치
pip install pykrx pandas matplotlib

# 1) 데이터 수집 → data/raw/supply_demand_{KOSPI,KOSDAQ}.csv
python scripts/fetch_supply_demand.py                    # 최근 3년, 코스피+코스닥
python scripts/fetch_supply_demand.py --start 2015-01-01 # 시작일 지정
python scripts/fetch_supply_demand.py --market KOSPI     # 한 시장만

# 2) 분석 + 차트 → data/processed/*.csv, outputs/charts/*.png, 콘솔에 상관표
python scripts/analyze_supply_demand.py
python scripts/analyze_supply_demand.py --market KOSPI --freq W
```

## 산출물

- `data/raw/supply_demand_{MARKET}.csv` — 원본 일별 (종가·개인·외국인·기관·기타법인). *gitignore, 로컬 보관*
- `data/processed/supply_demand_{MARKET}_{D|W|M}.csv` — 집계+누적순매수+수익률. *커밋 대상*
- `outputs/charts/supply_demand_{MARKET}_{D|W|M}.png` — 수급 vs 지수 차트. *커밋 대상*

## 상관표 읽는 법

```
 투자자   n  Pearson  Spearman
  개인  156   -0.67    -0.66     ← 개인이 살 때 지수는 내리는 경향(역행)
 외국인  156    0.85     0.84     ← 외국인이 살 때 지수가 오르는 경향(선행/동행)
  기관  156   -0.04    -0.05     ← 뚜렷한 관계 없음
```
- `+` 상관: 그 주체가 순매수할 때 지수가 오르는 경향
- `n`: 상관 계산에 쓴 표본 구간 수 (주간이면 주 수, 월간이면 월 수)

## 주의 (역할 5: 검증자)

- KRX는 국내망 기준이라 일부 클라우드/사내 프록시에서 차단될 수 있음 → **로컬 실행 권장**.
- 상관은 **인과가 아님**. "외국인이 사서 올랐다"가 아니라 "동행/선행 경향"으로만 해석.
- 리드-랙(선행성, 며칠 앞서는가) 분석과 개별 종목 수급은 다음 단계 과제.
