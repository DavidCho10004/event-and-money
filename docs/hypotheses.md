# 수급 가설 검증 대장 (2016-04 ~ 2026-06, 월별 백테스트)

수급(투자자별 순매수) 데이터 기반 매수 전략 탐색의 공식 기록.
**2026-07-14부로 수급 전략 탐색 영구 종료** — 이후 이 문서는 결과 열람용.

- 방법론: 각 월말 시점까지의 데이터만 사용(룩어헤드 차단), 균등 가중, 최대 20종목,
  벤치마크는 시총가중 시장 프록시 + 같은 시점·같은 개수 랜덤(시드 고정 100회 평균).
- 판정 기준(강건성): ①기간 분할(2016~20/2021~26) 양쪽 양수 ②최고 승리 달 3개 제거 후 양수 ③거래비용(왕복 0.3%) 후 양수.
- 원자료: `data/processed/backtest/*.csv` / 엔진: `수급/pipeline/backtest*.py` / 화면: `/backtest`

## 기각된 가설

| 가설 | 사전 예상 | 결과 | 기각 근거 (한 줄) |
|---|---|---|---|
| 수급 추종 — 삼박자(외인+·기관+·개인−)+지분율 3%p↑ (전략 a) | 지지 | **기각** | 상위 3개 달 제거 시 초과수익 소멸(코스피 6m +2.4→-0.2%p), 2016~20 구간 랜덤 이하 |
| 강도 상위 매수 (전략 b) | 지지 | **기각(턱걸이)** | 유일하게 기간 분할은 통과하나 상위 3 제거 후 +0.06%p — 사실상 0 |
| 교집합 정예화 (전략 c) | 지지 | **기각** | a와 동일 패턴, 상위 3 제거 후 -1.96%p |
| 미반응 매집 — 매집됐는데 아직 안 오른 종목 (전략 d) | 지지 | **기각** | 대조군 d′(이미 오른 쪽)에 전 구간 열세(+3.5 vs +5.2%p) — 데이터는 모멘텀 동행을 가리킴 |
| 폭락 레짐 조건부 진입 (H1) | 약한 지지 | **기각** | 평균 +6%p로 최대지만 두 시장의 기간 분할이 정반대, 상위 3 제거 시 음수 — 특정 반등 몇 번의 산물. 레짐 분위수가 인샘플 정의라는 한계도 있음 |
| 지속 매집의 절대 우위 (H2-i 단독) | 반반 | **기각** | 스파이크보다 항상 낫지만 랜덤을 이기지 못함(코스피 6m +0.5%p, 강건성 미통과) |

## 생존한 발견 (매수 신호 아님 — 해석 지침)

| 발견 | 사전 예상 | 결과 | 근거 |
|---|---|---|---|
| **H3 개인 쏠림 역신호** | 지지 | **부분 지지 — 전체 검증 중 유일한 통계적 유의** | 개인 순매수 강도 상위 20 종목은 코스피 1개월 -1.5%p(t=-2.39), 3개월 -3.6%p(t=-3.66) 유의 저성과. 6개월·코스닥은 방향만 음수(유의 X). → 스크리너의 "⚠ 개인 몰림" 경계 배지의 근거 |
| **H2 서열: 지속형 > 스파이크형** | 반반 | **서열은 일관 지지** | 3개월 연속 매집이 단월 스파이크보다 전 조합에서 우위(코스닥 6m 격차 +5.0%p). 절대 수익은 없으므로 "같은 강도라면 지속형을 우선 검토"라는 상대 지침으로만 사용. → 카드의 지속형/스파이크형 태그 근거 |

| B 빈도 — 직전 20거래일 강도 상위 30 진입 일수 | H2와 동형(랜덤 미달) | **부합 — 지지 없음** | 표본 9~11회뿐이며 상위 3 제거 시 전 조합 -3~-13%p |

**일·주 단위 수급 탐색 공식 종료.** 관찰 가능한 신호(종가→종가 양수)조차 시가 진입으로는 포획 불가 — "수급 정보는 다음날 시초가에 이미 반영된다"가 이 데이터의 결론.

## 조건부 1라운드 — 베이스 이등분 (C1~C3, 2026-07-18 종료 — A군 1~3 종료)

베이스(고정): 외인 강도 상위 30 ∩ 지속형(3개월 연속 순매수). 보유 6개월 고정(1개월 참고),
각 조건으로 베이스를 이등분해 충족/미충족 모두 계산(d/d′ 방식 대조군 내장), 다중 교차 금지.
원자료: `backtest_cond_*.csv` / 엔진: [backtest_conditional.py](../수급/pipeline/backtest_conditional.py)

**⚠ 라운드 전체 주의**: 베이스가 월평균 KOSPI 10.4 / KOSDAQ 8.2종목 → 분할군은 월평균 2.5~8종목으로
KOSPI 베이스 단독을 제외한 **전 셀이 '표본 희박'(월평균 10 미만)**. 아래 결과는 지침 수준으로만 사용.
베이스 자체도 랜덤 대비 우위 없음(KOSPI 6m +0.5%p 강건성 실패 / KOSDAQ 6m -3.5%p) — 기존 결론 재확인.

| 가설 | 사전 예상 | 결과 | 근거 (한 줄) |
|---|---|---|---|
| C1 밸류 조건부 — PBR 하위 50%(같은 달 시장 내 상대) | 반반 | **부합 — 유의차 없음** | 격차 t 전부 \|t\|<2. KOSDAQ 6m 저PBR +12.6%p로 보이나 t=1.74, 월평균 2.5종목, 최악의달 -81.9%, 상위 3 제거 시 -3.7%p — F1 붕괴와 동일한 초소형주 신기루 패턴 |
| C2 위치 조건부 — 52주 고점 대비 -20% 이내 | 고점 근처 우위 (d′ 방향) | **방향 적중 — 이번 라운드 유일한 유의 격차** | KOSPI 6m 격차 +8.0%p(t=2.06, n=90). 단 고점근처군 자체는 기간 분할 실패(2016~20 -2.3%p)로 매수 신호 아님. 강건한 쪽은 반대편: **낙폭군(KOSPI 6m)은 강건성 전 열 음수(-5.5~-8.8%p)** |
| C3 변동성 조건부 — 12개월 월수익률 표준편차 하위 50% | 저변동 약한 우위 (문헌 방향) | **빗나감 — 사전 예상 반대** | KOSPI 6m 오히려 고변동이 유의 우위(격차 -6.6%p, t=-2.12), 저변동군은 전 구간 음수(6m -4.4%p). 저변동 이상현상은 이 베이스에서 불성립 |

**종합**: 매수 신호 0 유지 (유의 격차 2건은 12셀 다중비교 중 2건 + 표본 희박 — 신호 승격 불가).
실전 지침 2개만 추가: ① **수급이 좋아도 낙폭 구간(-20% 초과)이면 피하라**(KOSPI, '떨어지는 칼' 회피 —
d′·F2 결과와 방향 정합) ② 저변동이 안전하다는 통념은 이 데이터에서 근거 없음. **A군 1~3 종료.**
